## 口径说明（重要）

1. **一对一铳率**：所有"放铳率"固定目标立直家——仅该立直家**最终荣和**时 win_tile 才是对其的放铳牌；立直家没和 → 该局对它的放铳事件为 0。
2. **现物定义**：对一家立直的现物 = 立直家全部舍牌（第一张→宣言牌→宣言后摸切）+ 宣言牌之后其他家所有舍牌（实时累积）。**现物铳率必须 = 0**（振听规则）——结果中现物组精确 0.000%，验证口径正确。
3. **局级 vs 行级**：`kyoku_result` 是整局结局，backfill 到该家所有行（放铳家 ~11 行/局）→ 行级计数会重复虚高。所有和率/放铳率已按局级去重。
4. **时点判定**：`turn` 是每家自己的出牌次数（副露后不递增），跨家不可比 → 用全局事件序号（parquet 行顺序）。
