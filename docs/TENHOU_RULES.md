## 1. 基本设定

| 项目 | 规则 |
|------|------|
| 起始点数 | **25000 点 × 4**（合计 100000）|
| 返点 | 30000 点 |
| 顺位马 | 10-20（一位 +20、二位 +10、三位 -10、四位 -20）|
| 赤牌 | 各 1 枚（赤5万/赤5筒/赤5索，共 3 枚）。**牌谱 ID 编码**：赤5m=16、赤5p=52、赤5s=88（`id % 4 == 0`，每类 5 号牌第 1 张副本；权威来源：kobalab/tenhou-log）|
| 食断 | 可选（有/无食断，房间设置）|
| 食替 | **禁止**（吃/碰后不能立即打出同种的对应牌）|
| 后付 | 有（允许先副露后立役）|
| 二翻缚 | **无**（任何情况下 1 翻缚）|
| 击飞 | 有：点数变负立即结束，负分也计入；**0 点继续** |
| 同点顺位 | 东 1 局座次决定 |

## 2. 点数/收支

- **本场棒**：连庄 +1 本场，和牌时每家多付 300×本场（四人麻将所有房间）
- **供托**：立直时 -1000 入供托；和牌者取走全部供托；**流局时供托留场**（下局继承）
- **双和（两家和了）**：有；**本场棒和供托归"上家"取**（从放铳者逆序第一家）
- **双和时亲家参与和牌则亲家连庄**（子家连庄优先于速死判定）

## 3. 立直

| 项目 | 规则 |
|------|------|
| 条件 | 点数 ≥1000 且还有下一巡摸牌 |
| 宣言牌放铳 | 供托不产生（立直不成立）|
| 振听立直 | 允许（空听/振听均可立直）|
| 立直后放过和牌 | 之后恒振听 |
| 立直后暗杠 | **只允许不改变待牌种类**的暗杠；**禁止送杠**（明杠）；牌姿/役增减不限制 |
| 立直后加杠 | 允许（改变待牌也可？——仅限"不影响待牌的暗杠"与加杠；送杠禁止）|
| 一发消除 | 发声喊杠/抢杠（仅加杠）到岭上摸牌前；连续加杠第 2 次不消除一发 |
| 双立直 | 有（第一巡立直）|

## 4. 副露/杠

- **食替禁止**：吃/碰后同巡不能打"能构成同面子"的牌
- **海底牌不能鸣**（不能吃/碰/大明杠海底牌）
- **抢杠**：加杠牌可被抢杠荣和；**国士無双可抢暗杠**（雀魂 DB 注明天凤有）
- **杠宝牌（カンドラ）**：
  - **暗杠后立即翻**（即乗り）
  - **明杠/加杠后延后翻**（打牌后或下一次岭上摸牌前）
- 四杠子无包牌（无责任支付）

## 5. 振听

| 类型 | 规则 |
|------|------|
| 舍牌振听 | 自己牌河含和牌牌（含被鸣走的）→ 恒振听 |
| 同巡振听 | 同巡内放过和牌（含抢杠）→ 同巡振听，到下次摸牌前不能荣和 |
| 解除 | **打牌可解除**同巡振听；**反向副露不能解除** |
| 振听判定 | 仅以"被打出的牌"判定（加杠/拔北亮出的非纯手牌除外）|

## 6. 流局（6 种，全部"连庄规则"见下）

### 6.1 荒牌流局（无 type）
- 牌墙摸完（剩 14 张王牌）无人和牌
- **听牌罚符**：不听者合计付 3000（+300×本场），按不听者人数均分；听牌者均分收入
  - 1 不听 → -3000；2 不听 → 各 -1500；3 不听 → 各 -1000
- **亲家听牌连庄，不听流庄**
- RYUUKYOKU 带 haiN = 听牌者手牌（T3 验证 100% 匹配）

### 6.2 流局满贯（type="nm"）
- 自己的牌河全幺九且未被鸣牌（自己副露过也成立）
- **比照自摸满贯清算**（代替听牌罚符）
- 亲家听牌连庄
- 多家同时成立则均可获得（各自清算）

### 6.3 九种九牌（type="yao9"）
- 第一巡摸牌后，手牌有 9 种以上（含）幺九牌，且之前无任何鸣牌（含暗杠）
- **可选择宣告**（也可放弃，如转向国士/流局满贯）
- 无条件连庄 +1

### 6.4 四风连打（type="kaze4"）
- 第一巡四家各打出**同一种风牌**、无鸣牌
- 无条件连庄 +1

### 6.5 四家立直（type="reach4"）
- 四家全部立直成立；最后立直者宣言牌放铳则不成立（按荣和结算）
- 无条件连庄 +1

### 6.6 三家和了（type="ron3"）
- 一家打牌同时放铳三家 → **不结算**，流局
- 无条件连庄 +1

### 6.7 四杠散了（type="kan4"）
- 场上 4 个杠且**不是同一家**开出；第四杠者摸岭上后打出无放铳
- 同一家 4 杠 = 四杠子（不流局，继续）
- 第四杠者岭上自摸 / 被抢杠 / 放铳 → 不流局（按和牌结算）
- 无条件连庄 +1

## 7. 连庄/轮庄

| 情形 | 连庄 |
|------|------|
| 亲家和牌 | 连庄 |
| 荒牌流局亲家听牌 | 连庄 |
| 荒牌流局亲家不听 | 流庄 |
| 中途流局（5 种）| **无条件连庄** |
| 双和含亲家 | 亲家连庄优先 |

## 8. 包牌（责任支付）

- **大三元 / 大四喜**有包牌
- 自摸 = 包牌者全额；荣和 = 包牌者半额；复合役满的包牌部分按包牌计算
- 本场棒也包
- **四杠子无包牌**

## 9. 和牌/役种要点

- **一翻役**：门清自摸/立直/抢杠/岭上开花/海底摸月/河底捞鱼/役牌（场风/自风/三元）/断幺/一盃口（门清）/平和（门清）
- **二翻役**：混全（食下）/一通（食下）/三色同顺（食下）/双立直/三色同刻/三杠子/对对/三暗刻/小三元/混老头/七对子
- **三翻役**：纯全（食下）/混一色（食下）/二盃口（门清）
- **六翻役**：清一色（食下）
- **悬赏**：一发/表宝/赤宝/里宝（不计入翻缚）
- **役满**：天和/地和/大三元/四暗刻（单骑=国士十三面等）/字一色/绿一色（无发也可）/清老头/国士無双（13 面）/大四喜/小四喜/四杠子/九莲宝灯/纯正九莲宝灯
- **数え役满**：13 翻以上（倍满以上累计）
- 门清自摸 20 符、七对子 25 符 2 翻、连风雀头 4 符、岭上自摸 +2 符
- **无地方役**：八连庄/人和/三连刻/一色三顺/十三不塔/百万石等一律不采用

## 10. 游戏结束条件

| 条件 | 说明 |
|------|------|
| 击飞 | 点数变负（负分计入；0 点继续）|
| All Last（南四局/西四局）| 东风战到南场、东南战到西场（南入/西入）|
| 速死（Sudden Death）| All Last 后有人 ≥30000（供托未收）时结束；亲家连庄优先；末亲（ラス親）和牌/听牌成一位自动结束 |
| 最大局 | 东风战最多南 4 局、东南战最多西 4 局 |
| 结束供托 | 一位取走全部供托 |
| 同点 | 东 1 局座次决定顺位 |
