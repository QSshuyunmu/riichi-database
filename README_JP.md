# Riichi Database — 天鳳データベースのための信頼できるイベントストリーム基盤

> **LLM による自然言語クエリ対応の天鳳データベースのための信頼できるデータ基盤**：天鳳 HTML 牌譜を厳密に検証されたイベントストリームへと変換する。
> 核心は「どんな結論が出たか」ではなく、**「解析したイベントストリームが正確だとどう証明するか」**——統計的結論は信頼性の傍証に過ぎない。

| 層 | 説明 |
|----|------|
| **最終目標** | LLM 自然言語クエリ対応の天鳳データベース（NL クエリ → 信頼できる統計）|
| **本プロジェクト** | データ基盤層：HTML 牌譜 → **信頼できるイベントストリーム**への完全パイプラインと検証体系 |
| **核心信念** | LLM の回答品質 **≤ データ品質**——データが信頼できなければ、その上の全てが信頼できない |

## 背景と動機

天鳳（tenhou.net）は公開牌譜（HTML/XML）を提供しており、麻雀研究の貴重なデータ源です。**LLM 自然言語クエリ**（例：「早巡に 5 を切って立直した場合、同色 1-4 の放銃率は？」）を支えるには、基盤となるイベントストリームが**絶対に信頼できる**必要があります——解析エラーは全ての下流クエリを体系的に汚染します。

本プロジェクトはその**信頼できるデータ層**を構築します。核心的貢献は**「HTML から信頼できるデータベースへ」の方法論**：解析 → 追跡 → 検証 → 准入。

```
│  将来層: LLM 自然言語クエリ (NL → 信頼できる統計)             │
└──────────────────────────────┬─────────────────────────────┘
                               ▲
┌──────────────────────────────┴─────────────────────────────┐
│  本層: 信頼できるイベントストリーム基盤 (本プロジェクト)        │
│                                                             │
│  天鳳 HTML/XML 牌譜 (354K 局)                                │
│      │  ① 解析層   pipeline/tenhou_to_mjai.py               │

│      │  ② 追跡層   pipeline/etl_v3.py                       │
│      ▼                                                      │
│  生イベントストリーム                                          │
│      │  ③ 検証ゲート   verify_gate.py L0-L3                 │
│      ├── ルール自己検証 (現物=0 / 反事実) ④                  │
│      ▼                                                      │
│  v3_200k_v2.parquet (2.05M 局)  ← ⑤ 准入層 (ADR-005)        │
│      │                                                      │
│      ├── クエリ群 analysis/ → results/                      │
│      └── (将来) LLM NL クエリ層                              │
└────────────────────────────────────────────────────────────┘
```

### 解析層（`pipeline/tenhou_to_mjai.py`）

HTML/XML 牌譜を**権威的な mjlog ビット配置**に基づいてイベントストリームへデコード。これまで **11 個の構造的バグ**を発見・修正：

| Bug | 修正 | 検証 |
|-----|------|------|
| 副露 m デコード誤り（下位2bit=席、型ではない）| 権威ビット配置で書き直し | 手牌保存ゴールデンテスト |
| 赤5 ID 判定誤り（`cp==3` vs 権威 `id%4==0`）| 赤5 = ID 16/52/88 | 300 ファイルで 0 不一致 |
| 副露 consumed コピーID 追跡誤り（31.8% 失敗）| カテゴリ単位除去（m はコピーを符号化しない）| meld 失敗 31.8% → 0 |
| 国士/七対待ち漏れ、ドラ循環等 8 件 | 個別修正 | INV-2 PASS |

**信頼根拠**：kobalab/tenhou-log（天鳳公式パーサー）との行レベル照合——独自デコードではない。

### 検証ゲート（L0-L3）

| ゲート | 内容 | 捕捉 |
|--------|------|------|
| L0 アンカーテスト | 8 ゴールデンケース | 関数レベル誤り |
| L1 ゴールデンセット | 200 XML（レアシナリオ）、AGARI 交差検証 ≥95% | レア解析誤り |
| L2 不変量 + 回帰 | INV-1..10 + P1-P15 | 系統的誤り |
| L3 統計ベースライン | 7 指標 vs nodocchi Phoenix | 統計的ドリフト |

![検証ゲート](docs/img/validation_gates.png)

### ルール自己検証（ゲームルールでデータを検証する方法論）

| 自己検証 | 原理 | 結果 |
|----------|------|------|
| **現物 = 0** | 立直者に対する現物（全捨牌 + 立直後他家捨牌）の放銃率は**正確に 0**（振聴ルール）——非ゼロは解析バグ | ✅ 0.000% |
| **赤5 反事実** | 赤5 を切った宣言者は普通 5 を持っていない（あれば普通 5 を切る）| ✅ 1.0% vs 44.6% |
| **役種率アンカー** | 平和/七対子/三色率 vs 権威ベースライン | ✅ 3 PASS |

![赤5反事実自己検証](docs/img/aka_counterfactual.png)

**統計口径の規約**（全クエリに適用）：
- **1対1の放銃率**：放銃率は対象立直者に固定（その立直者が栄和した時のみ）
- **局級重複排除**：和了/放銃率は局ごとに集計（行レベルは backfill で膨張）
- **時点判定**：グローバルイベントインデックス（プレイヤー毎の turn は席間で比較不可）

### 准入層（純粋性原則 ADR-005）

> **1 局の全アクションが検証に合格した場合のみデータベースへ。データ純粋性はデータ量に優先する。**

- コピー曖昧局（情報理論的 ~3.8%）は丸ごと破棄、品質低下での入库はしない
- 破棄は監査（無言では行わない）、生 XML は保持

### 交差検証

|------|------|

## 統計的発見（イベントストリーム信頼性の傍証として）

> これらの発見の意義：**麻雀の公認知識を再現できる = データが信頼できる**。完全な結果は [results/RESULTS_README.md](results/RESULTS_README.md)。

| クエリ群 | 代表的な発見 |
|----------|-------------|
| 安全度（b2）| 現物 0% < 筋 3.1% < 無筋 8.1%；無筋中張 13.0% が最も危険 |
| 赤牌（aka）| 赤5 切り後、同色 5x 待ち率 0%；端牌 1/9 待ちが増加 |
| 副露（v/furo_seq）| 役牌流 +393 vs 断幺流 -125 点；偽染手聴牌率 76% |
| タイミング（inferred）| 聴牌時 立直者への放銃 4.0% vs 3向聴時 0.8% |
| 立直（hata）| 中張 3 種類を切る → 一聴牌率 57.6%（0 種類：23.6%）|

## クイックスタート

> 生データは含まれていません（大容量のためリポジトリ除外）。ダウンロードスクリプトは本リポジトリに**ありません**——天鳳公開牌譜 XML を自身で入手してください。

```powershell
# 1. データ入手：天鳳公開牌譜 XML（354K 局、tenhou.net 参照）

# 2. 変換 + ETL
python pipeline/tenhou_to_mjai.py <input.xml>
python pipeline/etl_v3.py --input games_200k_v2 --out v3_200k_v2.parquet --workers 4

# 3. 検証（変更後は必ず実行）
python analysis/gate/run_guarded.py analysis/gate/verify_gate.py --all --data v3_200k_v2.parquet

# 4. クエリ実行（半荘級一様サンプリング）
python analysis/gate/run_guarded.py analysis/queries/b2_queries.py
```

**環境**：Python 3.13+（polars ≥1.40, psutil, matplotlib）；`PY` 定数は Windows 用 Python パス（環境に合わせて変更）。

## 既知の制限と信頼度グレーディング

| グレード | 説明 |
|----------|------|
| ✅ **直接引用可** | 現物/筋/無筋の放銃率、赤5 摸切り、不変量、役種率、基本統計 |
| ⚠️ **注意が必要** | 副露赤5 関連（m フィールドはコピーID を符号化しない）；槓後手切り未見内容；段位差（ベースラインは鳳凰卓、±2pp）|
| ❌ **使用不可** | 副露 consumed の具体的コピーID（情報理論的限界、純粋性原則で破棄）|
